# Neovim config

My personal Neovim 0.11+ configuration, using `lazy.nvim`, native LSP,
`blink.cmp`, and `nvim-treesitter`.

```sh
git clone https://github.com/ZHDI-1/nvimconf.git ~/.config/nvim
cd ~/.config/nvim && ./scripts/bootstrap.sh
```

See [docs/tooling.md](docs/tooling.md) for external tooling and PATH setup.
